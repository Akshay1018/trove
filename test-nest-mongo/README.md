# <%= projectName %>

A modern NestJS application with TypeScript, MongoDB, and JWT authentication.

## Features

- 🚀 NestJS framework
- 📝 TypeScript for type safety
- 🔐 JWT Authentication
- 📦 MongoDB with Mongoose
- 📚 Swagger API documentation
- ✨ ESLint + Prettier
- 🧪 Jest for testing

## Installation

```bash
# Install dependencies
npm install
```

## Running the app

```bash
# Development
npm run start:dev

# Production mode
npm run start:prod
```

## Test

```bash
# Unit tests
npm run test

# e2e tests
npm run test:e2e

# Test coverage
npm run test:cov
```

## API Documentation

Once the application is running, you can access the Swagger documentation at:

```
http://localhost:3000/api
```

## Environment Variables

Copy `.env.example` to `.env` and update the values:

```bash
cp .env.example .env
```
